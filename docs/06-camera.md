# 06 — 카메라 시스템

3개 모드 + 시나리오 연출 디렉터. 모드 전환은 항상 부드러운 트랜지션(easeInOutCubic, 0.8s).

## 1. 모드

### Orbit (기본, 3인칭 자유 시점)
- 자체 구현 궤도 컨트롤 (three/examples OrbitControls 기반 확장):
  - 좌드래그 회전, 우드래그/두 손가락 팬, 휠 줌 (거리 8~350m 클램프)
  - 바닥 아래 진입 방지 (polar angle 상한), 팹 경계 밖 타겟 클램프
- 개체 더블클릭 → 해당 개체로 타겟 이동 (Follow 진입 아님, 관심 이동만)

### Follow (개체 추적 3인칭)
- HUD 개체 목록/씬 클릭으로 대상 선택 → 어깨 뒤 오프셋(타입별: OHT는 하방 15°, AGV는 후상방)
- 스프링-댐퍼 스무딩 (위치 damp 4.0, 시선 damp 6.0). 대상 소멸 시 Orbit 복귀.
- 휠로 추적 거리 조절, 드래그로 대상 중심 회전 (오프셋 각 유지).

### FirstPerson (1인칭)
- 두 하위 모드:
  1. **탑승(Ride)**: 선택 개체(OHT/AGV/사람)의 시점에 카메라 부착. 미세 헤드밥(사람),
     레일 진동(OHT) 절차 노이즈. 자기 메시는 렌더 레이어 마스크로 숨김.
  2. **워크스루(Walk)**: WASD + 마우스룩, 자유 보행 (높이 1.7m 고정, 벽 충돌은 WalkGraph
     기반 간이 판정). 재난 대피 체험 용도.
- 포인터락 API 사용, ESC로 해제 → 직전 모드 복귀.

## 2. 입력 매핑

| 키 | 동작 |
|---|---|
| `1 / 2 / 3` | Orbit / Follow / FirstPerson |
| `Space` | 일시정지 토글 |
| `[ ]` | 배속 감소/증가 (0.5→1→2→4→8→16) |
| `E` | 다음 개체 추적 (`Tab`은 표준 UI 포커스 이동에 사용) |
| `F` | 선택 개체 Follow |
| `WASD / Shift` | 1인칭 이동 / 달리기 |

## 3. 시나리오 디렉터 (자동 연출)

재난 데모의 핵심 — 사용자가 조작하지 않아도 카메라가 사건을 따라간다.

- `CameraDirector`: 시나리오 이벤트(`emergencyPhaseChanged` 등)를 구독,
  단계별 샷 시퀀스를 실행:
  ```
  gasLeak 예시: 발생원 근접 샷(3s) → 존 확산 부감(5s) → 대피 인파 Follow(8s)
               → 비상구 집결 와이드(5s) → Orbit 복귀
  ```
- **사용자 개입 시 즉시 양보**: 입력 감지 → 디렉터 일시 중단, 10초 무입력 시 재개 여부 HUD 토스트로 질의.
- 샷 정의는 시나리오 JSON의 `cameraCues[]`로 데이터화 ([08] 스키마 참조).
- 목적 기반 휴머노이드 태스크는 `assigned`에서 로봇 Follow, `observing/interacting`에서
  작업 대상 Close-up, `reporting/returning`에서 다시 로봇 Follow로 전환한다. 재난 phase cue와
  같은 카메라 컨트롤러를 사용해 이동보다 현장 관찰·물리 조작의 가치를 먼저 보여준다.
- close-up 후보는 레이아웃의 주 통로, 열간 통로와 외곽 통로에서 고르고 설비 점유 사각형과
  시선이 교차하는 후보를 제외한다. 사람–로봇 인계는 두 pose를 잇는 선에 직각인 상부 구도로
  잡아 양쪽 움직임이 겹치지 않게 한다.
- 작업자 인지·양보·승인 장면과 로봇의 물리 작업 장면은 재난 phase cue보다 우선한다.
  이벤트 샷은 첫 프레임에 목표 구도로 컷하고, 일반 Orbit/Follow 조작은 기존 보간을 유지한다.

## 4. 구현 노트

- 카메라 상태는 zustand `cameraStore`에 **모드/대상 id만** 저장. 매 프레임 pose는 렌더 루프 로컬.
- 모든 모드는 `ICameraRig { update(dt), enter(from), exit() }` 인터페이스 구현 — 모드 추가 용이.
- Follow/Ride 대상 pose는 PoseBuffer에서 직접 읽음 (보간 포함) — sim 이벤트 대기 없음.
