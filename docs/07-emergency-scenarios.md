# 07 — 재난/비상 시나리오 설계

프로젝트의 존재 이유. **"인간과 로봇이 함께 일하는 환경에서 재난 발생 시,
사람·OHT·AGV·IGV가 어떻게 행동해야 하는가"**를 보여준다.

## 1. 공통 프레임워크: 비상 단계 (Emergency Phases)

모든 재난은 동일한 단계 상태머신을 따른다 (emergencySystem):

```
normal → detected → alarm → response → evacuation → allClear
                      │         │
                      └─ (의료: evacuation 없이 response → allClear 가능)
```

| 단계 | 시스템 동작 |
|---|---|
| **detected** | 발생원 인접 센서/사람이 감지. 발생원 개체 상태 변경, 국소 경고 |
| **alarm** | 전 팹 알람. 존 hazard 갱신 → nav 비용 반영. 경광등/사이렌 연출 시작 |
| **response** | 역할별 행동 오버라이드 발동 (아래 매트릭스). responder 파견 |
| **evacuation** | 사람 전원 대피 행동. 로봇 안전 상태 진입 |
| **allClear** | 단계적 복귀: 사람 재진입 → 로봇 재가동 → 미션 재개 |

## 2. 역할별 비상 행동 매트릭스 (핵심 산출물)

`EmergencyBehavior = normal | halt | yield | evacuate | respond | shelter`

| 개체 | 가스 유출 | 화재 | 응급 환자 |
|---|---|---|---|
| **사람 (일반)** | 풍상측(발생원 반대) 비상구로 **대피**. danger 존 회피 경로. 뛰는 애니(1.9m/s) | 최근접 안전 비상구로 대피. 연기 존 회피 | 환자 주변 3m 클리어, 통로 비우기(yield) |
| **사람 (responder)** | 방재복 착용 연출 후 발생원 접근 → 밸브 차단 작업 | 초기 진화 시도(30s) → 실패 시 대피 합류 | 최근접 2인이 환자에게 **달려감** → 응급처치 → 들것 반송 |
| **OHT** | danger 존 상공 통과 금지. 이동 중이면 **최근접 안전 세그먼트까지 진행 후 정지**(통로 상공 정차 금지) | 화재 베이 전 구간 정지 + 전원 차단 연출. 스프링클러 존 회피 | 정상 운행 유지 (천장이므로 무관, 단 환자 상공 서행) |
| **AGV** | 캐리어 소지 시 최근접 안전 지점에 내려놓고 **대피 경로에서 이탈**(사이드 파킹) — 사람 대피로 확보 최우선 | 즉시 사이드 파킹 + 정지. 소방 접근로 확보 | 환자 반경 10m 진입 금지, 우회. **구급 IGV 경로에 yield** |
| **IGV** | AGV와 동일 + 1대는 **방재 장비 운반 임무** 전환(responder 지원) | 소방 접근로 개방을 위해 후진 대피 | **1대가 구급 모드 전환**: 들것 스테이션 → 환자 → 의무실 반송 (경광 연출) |
| **설비** | 발생원: 가스 차단 + 배기 부스트 연출. 인접: 프로세스 안전 정지(holdable 공정은 hold) | 화재 베이: 전원 차단. 전 팹: 신규 투입 중지 | 영향 없음 (해당 베이 신규 반송만 보류) |

설계 원칙:
1. **사람 우선**: 모든 로봇 행동의 제1목적은 사람 대피로/구조로 확보.
2. **정지 위치도 계획이다**: 로봇은 "그 자리에 멈춤"이 아니라 "방해되지 않는 곳까지 이동 후 정지".
3. **로봇의 능동 기여**: IGV 구급 반송, 방재 장비 운반 등 로봇이 대응에 참여하는 모습을 연출.

## 3. 시나리오별 상세

### 3.1 가스 유출 (Gas Leak)

- 발생: `hazardCapable` 설비 1대에서 발화 (시나리오 지정 또는 랜덤).
- **확산 모델**: 발생원 중심 반경 성장 (r = r₀ + k·t, 기본 k 0.4m/s, 최대 30m).
  danger = 현재 반경, warning = 반경 × 1.8. 존 단위로 이산화하여 nav 비용 갱신 (1초 주기).
- 시각화: 반투명 가스 볼륨(황록색 `#c8e05a` 저채도, 불쾌한 색감 의도), 바닥 확산 데칼,
  hazard 존 경계 바닥 라인.
- 종료 조건: responder 차단 작업 완료(60 sim초) → 확산 정지 → 배기 감쇠(반경 축소) → allClear.

### 3.2 화재 (Fire)

- 발생: 설비 or 통로 지점. 화염 + 연기 기둥, 천장 연기층이 시간에 따라 확산.
- 확산: 인접 설비로 전파 확률 (30초마다 판정, 스프링클러 작동 시 전파 중지) — 데모용 단순 모델.
- **연기 = 시야**: 1인칭 워크스루에서 연기 존 진입 시 시야 포그 급증 — 대피 체험 연출.
- 소방 접근로: 화점까지의 지정 통로를 trafficSystem이 예약 — 로봇 진입 금지 시각화(빨간 통로 라인).

### 3.3 응급 환자 (Medical Emergency)

- 발생: 임의 작업자 1명 `collapse` 애니메이션 + 점멸 마커.
- 국소 대응 (전 팹 대피 없음): 목격자 알림 → responder 2인 달려옴 → 응급처치(30 sim초)
  → 구급 IGV 도착 → 들것 적재 → 의무실 반송.
- 이 시나리오의 핵심 볼거리: **AGV/OHT 교통류가 구급 경로를 실시간으로 비켜주는 모습**
  (그린 웨이브 — 구급 IGV 전방 경로의 교차점을 순차 예약).

## 4. 트리거/액션 이벤트 엔진

시나리오는 JSON 데이터 ([08] 스키마). 엔진은 범용:

- **Trigger**: `time(delay)`, `phase(entered)`, `entityAt(id, zone)`, `entityState(id, state)`,
  `all(...)`, `any(...)` (재귀 조합)
- **Action**: `setPhase`, `spawnHazard(kind, at, params)`, `overrideBehavior(selector, behavior)`,
  `dispatchResponder(n, to)`, `cameraCue(shot)`, `hudMessage(text, severity)`, `endScenario`
- selector: `type:agv`, `zone:bay-3-2`, `role:responder`, `id:...` — 대상 집합 질의.

## 5. HUD 연동

- 시나리오 패널: 발동 버튼 3종 (+ 발생 위치 선택 모드), 현재 단계 타임라인 표시.
- 상황판: 대피 완료 인원 / 총 인원, 정지 로봇 수, 경과 시간(simTime) — **데모의 정량 스코어보드**.
- 이벤트 로그 피드 (detected/alarm/… 각 전이와 주요 행동을 자막처럼 출력).

## 6. 검증 시나리오 (수용 기준)

1. 가스 유출 시 danger 존을 통과하는 사람/차량 경로 0건 (자동 테스트)
2. 전원 대피 완료 시간 < 5 sim분 (레이아웃 튜닝 지표)
3. 구급 IGV의 환자 도달 시간 < 90 sim초, 경로상 차량 간섭 0건
4. allClear 후 60 sim초 내 미션 처리량 평시 90% 복귀
