# 07 — 재난/비상 시나리오 설계

프로젝트의 존재 이유. **"인간과 로봇이 함께 일하는 환경에서 재난 발생 시,
사람·OHT·AGV·IGV가 어떻게 행동해야 하는가"**를 보여준다.

## 1. 공통 프레임워크: 비상 단계 (Emergency Phases)

모든 재난은 동일한 단계 상태머신을 따른다 (emergencySystem):

```
normal → detected → alarm → response → evacuation → allClear
                      │         │
                      └─ (의료: evacuation 없이 response → allClear 가능)
```

| 단계 | 시스템 동작 |
|---|---|
| **detected** | 발생원 인접 센서/사람이 감지. 발생원 개체 상태 변경, 국소 경고 |
| **alarm** | 전 팹 알람. 존 hazard 갱신 → nav 비용 반영. 경광등/사이렌 연출 시작 |
| **response** | 역할별 행동 오버라이드 발동 (아래 매트릭스). responder 파견 |
| **evacuation** | 사람 전원 대피 행동. 로봇 안전 상태 진입 |
| **allClear** | 위험원 통제·전원 집결 슬롯 대형 완성 확인. 일반 인원은 집결지에 머물고 위험 반경이 0이 된 뒤 정상 복귀 |

설비는 전 팹 일괄 정지하지 않는다. 가스는 확산 경계에 들어온 설비, 화재는 화점 인접 설비만
현재 공정 단계와 진행률을 보존한 채 `held`로 전환한다. 의료 대응은 설비 공정을 계속하며
환자 반경의 신규 투입만 보류한다.

## 2. 역할별 비상 행동 매트릭스 (핵심 산출물)

`EmergencyBehavior = normal | halt | yield | evacuate | respond | shelter`

| 개체 | 가스 유출 | 화재 | 응급 환자 |
|---|---|---|---|
| **사람 (일반)** | 인지 지연 후 수용 인원을 고려한 도달 가능 집결지로 **대피**. danger 존 회피 경로 | 같은 집결지 대피 규칙. 화점/응답 인력에 우선권을 양보 | 환자 주변에서 발생원 반대 방향으로 이동해 통로 비우기(yield) |
| **사람 (responder)** | 작업점에 잔류하지 않고 일반 인원과 함께 대피. 원격 EHS/출입통제가 허가와 1.5m 무인 구역을 확인 | 3인 초기 진화 → 통제 후 안전 집결점으로 후퇴해 대피 동선 개방 | 최근접 2인이 환자에게 **달려감** → 응급처치 → IGV 인계 |
| **OHT** | 현재 rail 구간을 안전하게 이탈해 위험 경계 밖 **rail-side 안전 대기 노드**로 이동. 대피 동선·위험 설비 인접 반송을 멈추되, 그 자리에서 급정지하지 않음 | 즉시 정지 | 정상 운행 유지 |
| **AGV** | 위험 반경 밖 안전 노드로 이동 후 정지 — 사람 대피로 확보 최우선 | 즉시 정지 | 환자 주변을 비우고 **구급 IGV에 yield** |
| **IGV** | 안전 노드로 이동, 1대는 **방재 장비 운반 임무** 전환 | 안전 노드로 이동 | **1대가 구급 모드 전환**: 환자 → 의무실 반송 |
| **휴머노이드** | 위험원 외부의 격리 밸브까지 RMF 태스크로 이동 → 현장 확인·물리 격리·결과 보고 | 사람 대피로를 방해하지 않는 안전 지점 정차, 허가된 초기 대응만 수행 | 의료 물품 전달·현장 영상/상태 보고, 구조 인력 동선 양보 |

### 가스 유출 시연의 카메라 문법

가스는 휴머노이드만 보여주는 장면이 아니다. 경보 뒤에는 `누출원 인지 → 팹·외부 집결지를 함께
담는 대피 전경 → 비상구의 대피 흐름 → RMF가 배정한 휴머노이드의 밸브·검지 작업`으로 시작한다.
그 뒤 센서 안정 전까지는 **로봇 작업 컷과 사람 대피 흐름 컷을 3.8~4.6초 간격으로 교차**한다.
실제 손·밸브·검지 상호작용이 발생하면 그 장면이 우선하며, 다음 교차 컷은 상호작용 종료 뒤에
이어진다. 센서 안정 뒤에는 반드시 `작업구역 해제` 와이드 컷으로 전환한 뒤 `휴머노이드 결과
보고·안전 복귀` follow 컷으로 넘어간다. 대피·집결 장면을 다시 고정하지 않는다. 따라서 관객은
**사람의 외부 대피와 로봇 격리가
같은 비상 시간축에서 병행됨**을 계속 읽게 된다.
| **설비** | 발생원: 가스 차단 + 배기 부스트 연출. 인접: 프로세스 안전 정지(holdable 공정은 hold) | 화재 베이: 전원 차단. 전 팹: 신규 투입 중지 | 영향 없음 (해당 베이 신규 반송만 보류) |

설계 원칙:
1. **사람 우선**: 모든 로봇 행동의 제1목적은 사람 대피로/구조로 확보.
2. **정지 위치도 계획이다**: 로봇은 "그 자리에 멈춤"이 아니라 "방해되지 않는 곳까지 이동 후 정지".
3. **로봇의 능동 기여**: IGV 구급 반송, 방재 장비 운반 등 로봇이 대응에 참여하는 모습을 연출.

대피자는 경보를 같은 tick에 일괄 인지하지 않는다. 각 사람은 seed에 고정되지만 단순 순번
패턴이 아닌 개인별 평시/비상 속도와 반응 지연을 갖는다. 운전원은 0.55~1.45초, 엔지니어는
1.15~3.10초의 결정적 반응 지연을 가진다. 이 시간 동안 먼저 위험원을 바라보고, 이어 배정된
출구 방향을 확인·지시하는 팔 동작을 한 뒤 개인별 1.56~1.72m/s 비상 속도로 출발한다.
이후 A*로 도달 가능한 집결지만 후보로
삼는다. 집결지는 경로 길이와 현재 배정 인원/수용량을 함께
평가해 한 번 배정하며, 순간 거리 변화만으로 목적지를 바꾸지 않는다. 위험 확대로 경로가
사라지면 다른 집결지를 다시 찾고, 어느 쪽도 도달할 수 없으면 위험 구역을 직선으로 가로지르지
않고 제자리 안전 정지한다. 집결지 진입 후에는 바깥 열부터 0.75m 육각 격자 슬롯을 채운다.
이미 선 사람도 통과자에게 소폭 양보해 군중 교착을 풀고, 전원이 자기 슬롯에 도착하기 전에는
`allClear`로 넘어가지 않는다. 각 사람은 도착 후 시설 측 확인 출구를 향해 정렬하며, 전원
위치 오차 0.12m와 방향 오차 0.08rad 이내가 해제 게이트다. 이동할 수 없는 `safeStop`·외부
RMF 로봇 앞에서는 1.8m부터 감속·측방 회피하고 최소 중심 간격 0.68m를 유지한다.
해제 단계에서도 위험 반경이 완전히 사라질 때까지 집결지를
이탈하지 않는다.

방재요원 6명은 무작위 순찰 위치가 아니라 서부·중앙·동부 안전 설비 권역에 2인 1조로 배치된다.
평시에는 생산 설비 점검에 섞이지 않고 대응 거점에서 대기한다. 따라서 의료·가스·화재 대응
시간이 난수 초기 배치나 직전 생산 작업에 좌우되지 않는다.

## 3. 시나리오별 상세

### 3.1 가스 유출 (Gas Leak)

- 발생: `hazardCapable` 설비 1대에서 발화 (시나리오 지정 또는 랜덤).
- **확산 모델**: 발생원 중심 반경 성장 (r = r₀ + k·t, 기본 k 0.4m/s, 최대 30m).
  danger = 현재 반경, warning = 반경 × 1.8. 존 단위로 이산화하여 nav 비용 갱신 (1초 주기).
- 시각화: 반투명 가스 볼륨(황록색 `#c8e05a` 저채도, 불쾌한 색감 의도), 바닥 확산 데칼,
  hazard 존 경계 바닥 라인.
- **사람 우선 대피**: 치명적 가스 경보에서는 responder를 포함한 모든 사람이 외부 집결지로
  대피한다. 밸브 작업점과 위험 반경 안에 사람을 남기지 않으며, live RMF에서는 원격 EHS
  작업허가와 무인 작업점 interlock만이 조작 조건이다.
- 격리 인과관계: 전원 대피·무인 작업점 확인 → 휴머노이드 손의 밸브 접촉(1.2초) → 폐쇄 위치
  도달(5.2초) → **휴머노이드 내장 가스 센서**의 잔류 농도 모니터링 → 센서 안정 피드백 확인
  (6.2초). 밸브 회전과 센서 상태 화면도 이 진행도에 연동한다.
- 병렬 로봇 대응: IGV와 AGV는 위험 반경 밖 설비로 이동해 비접촉 상태 점검을 수행한다.
  인접 설비는 HOLD 상태를 유지하며, 사람의 현장 재진입 없이 복구 판단 증거를 제공한다.
- 물리 작업점: 휠이 설치된 서비스 면 0.75m 앞에서 최종 5cm 이내까지 감속 접근하고,
  휠 방향 yaw를 맞춘 뒤에만 관찰을 시작한다. 양팔 2-link IK의 손 목표는 휠 토러스의
  전면 표면·링 중심선에 놓이며 회전 중 짧은 재그립 동작을 반복한다.
- 목적 효과: 허가 이후 1.5m 작업점의 distinct 진입자를 실제 pose로 기록한다. 정상 시연의
  수용값은 `human=0`, `humanoid=1`이며 사람 단독 작업시간을 임의 추정하지 않는다.
- 종료 조건: 마지막 센서 확인 뒤에만 확산 정지 → 전원 안전 집결·원격 설비 점검 → 배기 감쇠
  (반경 축소) → allClear → 사람의 평시 설비 업무 복귀. 시나리오 절대 시간만으로는 가스를
  통제하거나 `allClear`로 넘기지 않는다.
- 실패 조건: 센서 확인 전에 밸브 조작 실패를 주입하면 태스크를 `failed`로 종결하고 위험원은
  미통제로 유지한다. 로봇은 밸브에서 3m 이상 후퇴해 `safeStop`하고, 대피 중인 인력은 집결지에
  머문다. 후퇴 자체는 성공 격리 KPI나 allClear를 만들지 않는다.

### 3.2 화재 (Fire)

- 발생: 설비 or 통로 지점. 화염 + 연기 기둥, 천장 연기층이 시간에 따라 확산.
- 확산: 화점 중심의 성장/감쇠 반경을 존 단위 위험 비용과 인접 설비 HOLD에 반영한다.
- 시각화: 화염·연기 기둥, 바닥 경고 링, 설비 상태등으로 화점과 영향 범위를 표시한다.
- responder 3인은 화점에 우선 접근한다. 통제 완료 시 현재 위험 반경보다 2m 이상 먼, 서로
  3m 이상 떨어진 도달 가능 보행 노드로 후퇴해 대피 동선과 작업 구역의 순환 교착을 끊는다.
- 세 responder는 화점 중심에 겹치지 않는다. 2.65m 반경의 삼각 진압 위치로 접근한 뒤,
  양손 소화기 자세로 위험원을 향한다. 따라서 관제 화면에서는 대피 통로와 초기 진화 대형을
  동시에 읽을 수 있다.

### 3.3 응급 환자 (Medical Emergency)

- 발생: 임의 작업자 1명 `collapse` 애니메이션 + 점멸 마커.
- 국소 대응 (전 팹 대피 없음): 목격자 알림 → responder 2인 출동 → RMF가 환자 치료 경계
  밖의 실제 WalkGraph 노드를 키트 랑데부로 지정 → H2와 지정 responder가 2.2m 안에서 대면
  확인 → 양팔 수령 자세·인계 → responder가 환자에게 합류 → 2인 무릎 응급처치(30 sim초)
  → 구급 IGV 적재 → 의무실 반송.
- 휴머노이드는 쓰러진 환자에게 양보를 요구하지 않는다. 키트를 든 팔 접근이 완료된 뒤에만
  인계 이벤트를 내고, 빨간 키트는 로봇에서 responder 렌더로 실제 이동한다. 수령 자세는
  1.2초 유지되며 처치 시작 시 로봇·구조요원·환자 3자 카메라로 다시 전환한다.
- 적재 직후 responder는 치료 반경을 빠져나갈 때까지 구급 IGV보다 높은 통행 우선권을 유지해,
  근접한 두 주체가 서로 정지하는 교착을 막는다.
- 이 시나리오의 핵심 볼거리: **AGV/OHT 교통류가 구급 경로를 실시간으로 비켜주는 모습**
  과 환자·구조요원·휴머노이드의 목적 있는 물리 인계.
- 두 responder는 환자 양측의 서로 다른 1m 접근 위치를 먼저 확보한다. 키트를 받을 담당자와
  환자 상태를 확인하는 담당자가 같은 좌표로 겹치지 않으며, 인계 뒤에만 공통 처치 자세로 전환한다.

## 4. 트리거/액션 이벤트 엔진

시나리오는 JSON 데이터 ([08] 스키마). 엔진은 범용:

- **Trigger**: `time(delay)`, `phase(entered)`, `entityAt(id, zone)`, `entityState(id, state)`,
  `all(...)`, `any(...)` (재귀 조합)
- **Action**: `setPhase`, `spawnHazard(kind, at, params)`, `overrideBehavior(selector, behavior)`,
  `dispatchResponder(n, to)`, `cameraCue(shot)`, `hudMessage(text, severity)`, `endScenario`
- selector: `type:agv`, `zone:bay-3-2`, `role:responder`, `id:...` — 대상 집합 질의.

## 5. HUD 연동

- 시나리오 패널: 발동 버튼 3종 (+ 발생 위치 선택 모드), 현재 단계 타임라인 표시.
- 상황판: 대피 완료 인원 / 총 인원, 정지 로봇 수, 경과 시간(simTime) — **데모의 정량 스코어보드**.
- 이벤트 로그 피드 (detected/alarm/… 각 전이와 주요 행동을 자막처럼 출력).

## 6. 검증 시나리오 (수용 기준)

1. 가스 유출 시 danger 존을 통과하는 사람/차량 경로 0건 (자동 테스트)
2. 전원 대피 완료 시간 < 5 sim분 (레이아웃 튜닝 지표)
3. 휴머노이드 키트 인계와 작업 완료, 구급 IGV의 환자 인계가 각각 90 sim초 이내이며
   구급 경로 차량 간섭 0건
4. allClear 후 60 sim초 내 미션 처리량 평시 90% 복귀
