# FabWorld 시연 PRD

상태: `DECLARED` · 기준일: 2026-07-30

제품 중심 명제는 “Open-RMF가 사람용 작업 환경에서 휴머노이드를 배정하고, 사람 대신 위험한
수동 작업을 수행하되 EHS와 PLC의 독립 증거가 있어야 성공으로 판정된다”이다. 재난은 이 장점을
드러내는 상황이며 제품 자체의 목적은 아니다. 현재 화면의 구현 경계와 실기 미검증 항목은
`docs/11-implementation-audit.md:8`과 `docs/11-implementation-audit.md:88`에 구분되어 있다.

## 선언된 사용 사례

| ID | 주 행위자 | 사용 사례 | 성공 결과 |
|---|---|---|---|
| US-01 | 관람자 | 평시 팹의 생산·물류·사람 작업을 관찰한다. | 재난 전에도 운영 목적과 로봇의 역할을 이해한다. |
| US-02 | 운영자 | Open-RMF 설비 점검 태스크를 요청한다. | 휴머노이드가 배정·이동·관찰·보고한다. |
| US-03 | 운영자·EHS | 가스 이상에 휴머노이드 격리를 수행한다. | 허가→접촉→폐쇄→센서 확인 뒤에만 통제된다. |
| US-04 | 구조요원 | 휴머노이드에게 응급 키트를 인계받는다. | 대면 확인·소유권 이전·처치·이송이 이어진다. |
| US-05 | EHS | 화재 시 사람과 로봇을 안전하게 분리한다. | 사람은 집결하고 로봇·설비는 안전 상태가 된다. |
| US-06 | EHS 승인자 | 가스 작업허가를 발급하거나 철회한다. | 실행기는 현재 허가 없이는 팔 작업을 시작하지 않는다. |
| US-07 | RMF 운영자 | 실제 RMF pose·태스크를 화면에 연결한다. | 외부 상태가 화면의 이동·작업 단계 권위를 가진다. |
| US-08 | 시연 운영자 | 현장 네트워크 없이 검증 trace를 재생한다. | 합성·현장 기록·live가 명확히 구분된다. |
| US-09 | 시연 운영자 | 밸브·센서·통신 실패를 주입한다. | 성공 오표시 없이 후퇴·정지·EHS 인계가 보인다. |
| US-10 | 관람자 | 책임 주체별 임무 증거와 효과 KPI를 확인한다. | RMF→EHS→휴머노이드→PLC/GAS 인과관계를 읽는다. |
| US-11 | 시연 운영자 | 진행 중인 live 화면을 새로고침한다. | 비상 상태·태스크·허가 증거가 복구되고 중복 booking은 생기지 않는다. |

## 범위 밖

실제 E-stop, 로봇 균형 제어, 팔 힘 제어, 안전 PLC의 최종 권위는 이 저장소가 소유하지 않는다.
실제 action executor가 Bridge 조회를 인터록으로 쓰는지와 현장 좌표 오차는 외부 수용 시험
대상이다. `docs/12-rmf-bridge-deployment.md:371`
