# 05 — 비주얼 디자인 (색채 · 조명 · 머티리얼)

목표: "게임 같은 화려함"이 아니라 **클린룸 특유의 정갈하고 미래적인 산업 미학**.
정보 전달(상태·위험)이 색으로 즉시 읽혀야 한다.

## 1. 아트 디렉션 키워드

- **Clean / Clinical / Luminous** — 밝은 무채색 기조 + 공정별 절제된 액센트
- 실제 팹 레퍼런스: 백색 raised floor(타공 패턴), 스테인리스 설비, 천장 FFU 조명 그리드, 베이별 색 코딩 사이니지

## 2. 색채 체계

### 기조 (무채색 90%)

| 요소 | 컬러 | 비고 |
|---|---|---|
| 바닥 | `#e8ecf1` | 타공 패턴 텍스처(절차 생성), roughness 0.35 |
| 벽/천장 | `#f4f6f9` / `#dde3ea` | |
| 설비 본체 | `#cfd6de` ~ `#9aa5b1` | 타입별 2단 명도 |
| 레일 | `#7d8794` + 액센트 `#4a5568` | |
| 배경(포그) | `#eef2f7` | 원거리 페이드 |

### 공정 밴드 액센트 (채도 있는 10%)

베이 사이니지·바닥 라인·설비 트림에만 사용:

| processBand | 컬러 | |

| etch | `#38b2ac` | 틸 |

### 상태/시맨틱 컬러 (emissive)

| 의미 | 컬러 | 사용처 |
|---|---|---|
| 정상 가동 | `#3ddc84` | 설비 상태등, 차량 LED |
| 대기/idle | `#8899aa` | |
| 반송 중 | `#42a5f5` | 캐리어 하이라이트 |
| 경고 | `#ffb020` | warning 존 바닥 라인 |
| 위험/비상 | `#ff3b30` | 경광등, danger 존, 대피 화살표 |

규칙: **시맨틱 레드/그린은 비상 연출 전용으로 아껴서**, 평시 화면에 붉은 요소를 두지 않는다 →
재난 발생 순간의 시각 대비 극대화.

## 3. 조명 설계

물리 그럴듯함보다 **가독성과 균질함** 우선. 클린룸은 실제로도 그림자 없는 균질광이다.

```
1. HemisphereLight  (sky #ffffff / ground #d8dee7, intensity 0.9)  — 기본 충전광
2. DirectionalLight (0.8, 살짝 기운 각도)                          — 유일한 그림자 캐스터
3. Environment HDR  (industrial, intensity 0.35)                   — 금속 반사
4. 천장 FFU 등: emissive 인스턴스드 플레인 (실광원 아님)           — 룩 형성
5. 카메라 근접 보조광 (SpotLight, 카메라 추종, 0.4)                — 1인칭/근접 디테일
```

- 톤매핑 ACESFilmic, exposure 1.0. 전체 라이트 수 ≤ 3 (실광원 기준) — 포워드 렌더 비용 고정.

### 비상 시 조명 연출 (시나리오 연동)

| 단계 | 연출 |
|---|---|
| 발생 | 발생원 반경 경광등(빨강 회전광 인스턴스드) 점멸 시작, 국소 포인트라이트 1개 허용 |
| 전파 | 전체 ambient 10% 감광 + 비상구 유도등 emissive 3× |
| 대피 | 바닥 유도 라인(대피 경로) 흐르는 화살표 셰이더, 사이렌 펄스 링 |
| 해제 | 3초 페이드로 평시 복귀 |

## 4. 머티리얼 가이드

- 기본 `MeshStandardMaterial`. 정적 대형 면(벽/천장)은 `MeshLambertMaterial`로 강등 가능.
- 파라미터 표준: 바닥 rough 0.35 / metal 0.05, 설비 rough 0.5 / metal 0.3, 레일 rough 0.4 / metal 0.6.
- 텍스처는 절차 생성(캔버스) 타일 3장 이내 (바닥 타공, 설비 패널 라인, 그레이팅). 외부 텍스처 자산 최소화.
- emissive 요소는 전부 인스턴스드 + 인스턴스 컬러로 상태 표현 (머티리얼 교체 금지).

## 5. FX (비상 연출 전용)

| 효과 | 구현 | 예산 |
|---|---|---|
| 가스 유출 | 반투명 볼륨 스프라이트(빌보드 파티클 ~200, additive 아님·안개형) + 바닥 확산 데칼 | 1 draw call |
| 화재 | 셰이더 화염 쿼드(노이즈 스크롤) + 연기 파티클 ~300 + 천장 연기층 평면 | 3 draw call |
| 응급환자 | 쓰러짐 애니메이션 + 점멸 마커 링 + 구조 경로 라인 | 2 draw call |
| 사이렌 링 | 확산 링 InstancedMesh (최대 300, 이전 프로젝트 계승) | 1 draw call |
| 대피 유도 | 바닥 화살표 흐름 셰이더 (경로 폴리라인 따라 UV 스크롤) | 1 draw call |

모든 FX는 `fxDensity` 품질 파라미터로 파티클 수 스케일.
